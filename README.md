# 교육공무직원 연차미사용수당 계산기

## 다운로드

[최신 정식판과 변경 내역](https://github.com/isilria/education-leave-calculator/releases/latest)에서 `LeaveCalculator.exe`를 받으세요.

## 이 저장소

공개 배포 전용 저장소입니다. 소스는 비공개 저장소 `isilria/education-leave-calculator-source`에서 관리합니다.

| 위치 | 내용 |
|---|---|
| GitHub Releases | 버전별 실행 파일, 소스 ZIP, 자동 업데이트 정보 `update.json` |
| `CHANGELOG.md` | 전체 변경 내역 |

설치된 프로그램은 최신 릴리스의 `update.json`을 확인합니다. 화면 버전과 태그 표기가 다릅니다. 예를 들어 화면 버전 `b1.0.4`의 태그는 `v1.0.4.0`입니다.
